# Legacy Companion Summon System (Archived)

**This document describes a removed system and is not an implementation guide.**

The former egg, fragment, collection, deployment, companion-AI, companion-market,
training, forging, and summon-duel mechanics were removed on 2026-11-06.
Their commands and runtime routes are not part of the current RPG.

The replacement is the independent **Summon Card** mechanic. Players own
special cards, moderators grant/revoke them, and each card activates one
signature ability during PvE combat. Summon cards do not deploy companion
entities and do not use the UserCard collectible economy.

See [summon-cards.md](summon-cards.md) for the current catalog, commands,
combat rules, cooldowns, GIF pipeline, and QA instructions.
