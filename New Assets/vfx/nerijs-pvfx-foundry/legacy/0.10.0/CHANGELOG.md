# Changelog

## 0.10.0 — 2026-09-29

- Add Hush Mechanics: Hush Lock (36-frame silence/cancel one-shot), Echo Shuttle
  (40-frame directional returning-probe loop), and Resonant Break (34-frame
  stored-sound release one-shot), all 96×96 at 20 FPS with pivots and markers.
- Preserve all 41 earlier assets and canonical pixels: 44 effects, 88 sheets,
  and 1068 canonical frames per layout. Output-only CC0 remains unchanged.

## 0.6.0 — 2026-09-04

- Added nine Impossible Materials effects: Foldstep, Mercury Molt, Cinder
  Orchid, Suturelight, Hourglass Splinter, Choir Moths, Ferrospine, Rootscript,

## 0.5.0 — 2026-09-01
