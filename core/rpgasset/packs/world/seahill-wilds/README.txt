2. TECHNICAL SPECIFICATIONS
--------------------------------------------------------------------------------
- Format:             glTF 2.0 Binary (.glb), textures embedded
- Geometry:           Stylized low-poly, 336 - 41,332 triangles per asset
                      (pebbles and fence posts at the low end, the Supply Wagon,
                      Wheelbarrow and Grand Oaks at the high end)
- Textures:           One shared 1024x1024 color atlas. Each .glb embeds its own
                      copy so it works standalone; Textures/wilds-atlas.png is
                      the same atlas for re-texturing or custom materials.
- Materials:          The atlas material on every asset, plus small accent
                      materials on flowers, berries, birch leaves and campfire
                      flames
- Metric Scale:       1 Unit = 1 Meter (calibrated for standard game engine grids)
- Pivot Points:       Centered at the ground base for intuitive snapping & placement
- Colliders:          Ready to generate simple box / convex hull colliders in-engine

3. ENGINE INTEGRATION GUIDE
--------------------------------------------------------------------------------
[GODOT 4 - OPEN AS A PROJECT]
1. In the Godot Project Manager, click Import and select this folder's
   "project.godot". Built and tested with Godot 4.7.
2. Press F5 to run the master diorama, or open
   "Godot_Showcase/seahill_wilds_complete.tscn" and preview CameraIsometric.

[GODOT 4 - ADD TO AN EXISTING PROJECT]
1. Copy the "Models", "Textures" and "Godot_Showcase" folders into one folder
   of your project. Leave "project.godot" out: Godot skips any folder that
   contains its own project.godot.
2. Godot automatically imports .glb files as 3D scenes.
3. The master scene loads the models from "../Models/GLB/", so keep those
   folders side by side.
4. Use MeshLibrary to convert floor tiles into a GridMap for 1-click level building.

[UNITY]
1. Install a glTF importer from the Package Manager: glTFast
   (com.unity.cloud.gltfast) or UnityGLTF. Unity does not import .glb without one.
2. Drag the "Models/GLB" folder into your Assets folder.
3. If using Universal Render Pipeline (URP), ensure materials are assigned to
   URP/Lit or URP/Simple Lit.

[UNREAL ENGINE 5]
1. In the Content Browser, click Import and select the .glb files
   (UE 5.1+ imports glTF natively through Interchange).
2. Check "Import Materials" and "Import Textures".

[BLENDER]
1. Go to File > Import > glTF 2.0 (.glb/.gltf).
2. Select any model to inspect, modify, or extend.

4. THE MASTER DIORAMA
--------------------------------------------------------------------------------
"Seahill Valley": a 20m x 16m tiered block in six biomes, joined by one
two-tile trail that steps down from the mountains to the water:
- Alpine Sanctum: snow, glacial ice pool, shrine, monolith, graves, juniper
- Pine & Birch Woods: pines, birch grove, dead tree, ferns, tall bushes
- Oak Grove: the three oaks among autumn and berry bushes
- Trading Outpost: tent, campfire, wagon, well, crates, barrels, fence line
- Wildflower Meadow: pink, white, yellow and purple flower drifts
- Lagoon & Wetland: reed beds, mud flat, sand beach, driftwood, shore rocks
