# PVFX Foundry format 0.1

## Stability

`pack.json` uses `pvfx.asset-pack/0.1`. The legacy machine ID
`pvfx.foundry-thirteen` and all effect IDs are stable even though the public
product name is now PVFX Foundry.
Patch releases do not intentionally change canonical pixels. Any intentional
pixel, timing, effect, or layout change receives a new minor pack version and a
changelog entry.

## Directory contract

Each effect has two directories:

```text
effects/<effect-id>/grid/sprite-sheet.png
effects/<effect-id>/grid/manifest.json
effects/<effect-id>/packed/sprite-sheet.png
effects/<effect-id>/packed/manifest.json
```

The pack index points to every artifact and records its SHA-256. The top-level
checksum inventory binds every other file in the payload.

## Generic export manifest

Each manifest is generated by the canonical Pixel VFX Studio exporter. It
contains source, dependency, animation, renderer, and profile identities;
canvas and pivot data; loop intent; lifecycle markers; exact frame durations;
visible and trim bounds; sheet placements; and canonical raw-RGBA pixel hashes.

Grid and packed manifests for one effect must agree on all canonical animation
facts. Only layout-specific trim and placement fields differ.

## Provenance

`PROVENANCE.json` records the source commit/ref, renderer, export profiles, and
pack definition hash used to assemble the payload. The release ZIP has sibling
checksum and provenance files so the archive can be verified without a
self-referential hash.
