# New Assets / vfx

One folder per source pack; every folder carries its own README with the source URL, author, license terms and what was extracted. Archives were downloaded 2026-11-14, integrity-checked, extracted and then removed - folders hold unpacked assets only.

**Free-tier caveats:** Slash FX holds the free demo (full version is paid), Pixel Art Spells holds the free starter (full pack is paid), Holy Spell Effect holds the free Holy VFX 01-02 files. Pipoya and artistworld packs allow commercial use but forbid reselling or redistributing the assets; artistworld additionally forbids AI-training and NFT use; Sangoro is CC BY-SA 4.0, nerijs PVFX Foundry and Pixogen Lite are CC0.

**Not included:** gabrielaguiarprod's Unique Toon Projectiles Vol.1 - the itch.io page hosts no downloadable files (the pack lives on the Unity Asset Store behind a Unity login), so it could not be fetched.

**Formats:** mostly PNG sprite sheets plus JSON metadata (nerijs, pixogen); vefects arrived as a Unity .unitypackage and was reconstructed into `Assets/` with .meta files and previews; sangoro is loose PNGs. All folders sit next to this README and are ready for the card renderer.
