# Group Activity and AI Summary Command Flow (`record` / `summary` / `recap` / `activity` / `active` / `inactive` / `tagactive` / `taginactive`)

## 💡 Noob-Friendly Explanation
* **What it does**: The bot can keep track of how active your chat is and help you summarize long conversations! 
  * **Summary**: If you miss a bunch of texts, you can ask the bot to summarize them so you don't have to scroll up and read everything.
  * **Activity Statistics**: You can see who is talking the most (the active leaderboard), who hasn't spoken in a while (the inactive list), or tag active/inactive people to get their attention.
* **How to use it**:
  * **Toggle Recording**: `.j record on` (enables message buffering for summaries).
  * **Get Summary**: `.j summary` or `.j recap` (creates an AI breakdown of recent chat).
  * **Stats**: `.j activity` (total message counts), `.j active 1h` (shows active users in the last hour), `.j inactive 1d` (shows who has been silent for a day), `.j tagactive 1h Wake up!` (mentions active users).
* **Under the Hood (Simple)**: When recording is ON, the bot saves every message sent in the chat into a temporary circular buffer (holds the last few hundred messages). When you type `.j summary`, it feeds these messages to the Groq AI, which rewrites them into a clean recap. For activity commands, the bot queries its database log to count how many messages each participant sent during the selected timeframe, ranks them, and outputs the list.

## 3. Step-by-Step Code Execution Flow

### Step 1: AI Summary Generation (`summary` / `recap`)
* **File Path**: [core/engine.js](file:///home/mellow/Desktop/Joker/whatsapp-bot/core/engine.js#L10255-L10305)
* **Inputs**: Chat identifier `chatId`
* **Outputs**: Formats a text summary block generated by LLM

```javascript
if (primaryCmd === "summary" || primaryCmd === "recap") {
  const history = getBufferMessages(chatId); // Fetch from in-memory cache
  if (history.length < 5) return reply("Not enough messages to summarize yet.");

  const transcript = history.map(h => `${h.senderName}: ${h.text}`).join("\n");
  const response = await groq.chat.completions.create({
    messages: [
      { role: "system", content: "You are a helpful assistant. Summarize the following WhatsApp chat conversation concisely, listing key topics and active speakers." },
      { role: "user", content: transcript }
    ],
    model: "llama-3.1-8b-instant"
  });
  await reply(response.choices[0].message.content);
}
```

### Step 2: Activity Aggregation (`active` / `inactive`)
* **File Path**: [core/engine.js](file:///home/mellow/Desktop/Joker/whatsapp-bot/core/engine.js#L10321-L10344)
* **Inputs**: Chat identifier `chatId` and period duration argument string
* **Outputs**: Returns a sorted array of active user accounts containing message counts

```javascript
const periodArg = lowerTxt.replace(`${botConfig.getPrefix().toLowerCase()} active`, "").trim() || null;
const periodMs = parseTimePeriod(periodArg) || 24 * 60 * 60 * 1000; // defaults to 24h

const activity = await getChatActivityForPeriod(chatId, periodMs);
const sorted = activity.sort((a, b) => b.count - a.count).slice(0, 15);

let text = `🏆 *Most Active Members*\n\n`;
sorted.forEach((user, i) => {
  text += `${i + 1}. @${user.userId.split("@")[0]} — *${user.count}* msgs\n`;
});
await sock.sendMessage(chatId, { text, mentions: sorted.map(u => u.userId) });
```

## 4. How to Modify
* **Change the Summary LLM Model**: Update the model name argument (`llama-3.1-8b-instant`) in `engine.js` around line 1166 (or search for `summary` model parameter).
* **Adjust Message Buffer Capacity**: Modify the maximum size limit of message transcripts kept in the memory buffer inside `BufferManager.js`.
* **Alter Active Leaderboard Limit**: Customize the `slice(0, 15)` count to display more or fewer active members in `engine.js` at line 10327.
